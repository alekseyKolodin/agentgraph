# Репо команды agentgraph Teamwork

Здесь команда ведёт проекты: ТЗ, архитектуру, дизайн, задачи и спринты. Код живёт в отдельных репо — проект ссылается на них в `project.yaml`. Файлы пишет agentgraph, но это обычные markdown и YAML: их можно читать и править где угодно, история — в git.

## Как подключиться

1. Установи agentgraph и открой его интерфейс.
2. Проверь, что git знает тебя: `git config --global user.name` и `git config --global user.email`. По email agentgraph узнаёт тебя среди участников.
3. Teamwork → «Подключиться по ссылке» → вставь ссылку на этот репо. agentgraph клонирует его в `~/.agentgraph/teams/<slug>/repo` и предложит добавить тебя в участники.
4. Для репо кода проектов укажи свои локальные папки, если agentgraph не нашёл их сам.

Изменения расходятся автоматически: каждая правка — коммит, отправка через несколько секунд, получение в фоне.

## Что где лежит

```
teamwork.yaml              команда: название, префикс номеров задач, колонки доски, участники, flow по умолчанию
flows/                     flow агентов команды: черновик ТЗ, архитектуры и дизайна, разбивка на задачи, задача в работу
project-template/          заготовки документов нового проекта — правьте под свою команду
projects/<slug>/
  project.yaml             описание проекта и репо кода
  prd.md                   ТЗ: требования строками «- FR-1. …» и «- NFR-1. …», номера не переиспользуются
  architecture.md          архитектура
  design.md                дизайн
  docs/                    прочие документы и картинки
  tasks/<ID>.md            задача: поля во frontmatter, описание и критерии приёмки ниже
  comments/<ID>/*.md       комментарии к задаче, по файлу на комментарий
  sprints/<n>.yaml         спринт: запланирован, активен или закрыт; задача входит в спринт своим полем sprint
```

## Правила проекта для агентов

Если в папке проекта завести `CLAUDE.md`, он станет памятью агентов по задачам этого проекта, как `CLAUDE.md` репо кода. Flow в `flows/` — процесс команды: их можно править, они проверяются по схеме agentgraph.
