Цель и проблема, Для кого, Сценарии — без правок

Требования

FR-1
Выгрузка счетов за выбранный период в CSV. Период включает обе границы.
FR-2
Колонки и их порядок — как в шаблоне бухгалтерии docs/columns.md.
FR-3
Кодировка файла — UTF-8. на выбор в форме: CP1251 для 1С, UTF-8 с BOM для Excel.
1 из 4Вы ответили агенту: 1С ждёт CP1251, а Excel открывает только UTF-8 с BOM.
FR-4
Пустой период даёт файл только со строкой заголовков, а не ошибку.
FR-5
Файл больше 50 000 строк делится на части с номером в имени.
FR-6
Выгрузка по расписанию раз в месяц на почту бухгалтерии.
FR-7
Фильтр по контрагенту: один или несколько.
FR-8новое
Журнал выгрузок: кто, когда и за какой период выгружал. Видит роль «Админ».
2 из 4 · принятоИз задания: журнал выгрузок. Номер — следующий свободный.
Нефункциональные требования — без правок

Вне рамок

  • Выгрузка в XLSX и загрузка в 1С через API: отдаём только файл.
  • Правка счетов из выгрузки.
3 из 4Уточняет FR-3: интеграции с 1С по API в проекте нет.
