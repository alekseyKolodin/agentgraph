## 1. «Мои задачи» на главной (spec §11)

## 2. Диалог выхода (spec §7.5)

Как сейчас данные приходят: `main.ts` после старта сервера динамически импортирует `sessions-server.js` → `liveSessionNames()`. Тот же
путь для Teamwork: `teamwork-server.js` → `unsentTeams()` (команды с коммитами, которых нет в репо команды: `slug`, `title`, `unpushed`,
`error` из строки синхронизации, `pushing` — отправка идёт сейчас) и `pushTeams(slugs)` (`service.sync` каждой). Вся логика — в
`src/quit-dialog.ts` без Electron (тест `src/quit-dialog.test.ts`): `quitPrompt` — текст и кнопки (туда же переехал `sessionsLine`),
`askQuit(deps)` — цикл вопроса с подменяемыми источниками и показом окна; `main.ts` только передаёт настоящие (`confirmQuit`):

- только сессии — как было: «Завершить сессии и закрыть» / «Отмена», абзац про состояние пространства;
- неотправленные изменения — «Не отправлено в Teamwork: «Платежи» — 3 изменения (<причина одной строкой, до 120 знаков>)…» и кнопки
  «Отправить и закрыть» (по умолчанию) / «Закрыть без отправки» / «Отмена»; вместе с сессиями — оба абзаца и «Отправить, завершить
  сессии и закрыть»;
- «Отправить…» синхронизирует команды (не дольше 20 с) и выходит, если всё ушло; не ушло — тот же диалог с заголовком «Изменения
  Teamwork не отправились» (или «…ещё отправляются», если push не успел за 20 с — тогда и в строке команды «ещё отправляется»), без
  «Отправить», по умолчанию «Отмена».

`before-quit` теперь откладывает выход всегда (коммиты считает git, асинхронно; подсчёт ограничен 3 с), спрашивать не о чем — выходит
сразу; диалог не открылся (исключение) — выходит, как раньше без вопроса. SIGTERM/SIGINT и перезапуск после автообновления
(`quitConfirmed`) по-прежнему без вопроса. «Остаться» в вопросе о несохранённых изменениях окна теперь всегда снимает `quitConfirmed`
(раньше только при перезапуске после обновления — с новым `before-quit` следующий Cmd+Q проходил бы без вопроса). `stopServer` ждёт
`stopTeamwork()` не дольше оставшегося срока остановки (не меньше 2 с): push без сети висит до таймаута git (2 мин), а выход ждать его
не должен — коммиты остаются в клоне.

**Не видел живьём**: Electron не запускал. Проверены `quitPrompt` и `askQuit` (всё ушло — выход без второго окна, не ушло — второе окно и
оба ответа, push завис — не ждём дольше срока и пишем «ещё отправляются», подсчёт завис — выход без вопроса, «Отмена» ничего не
отправляет) и `unsentTeams`/`pushTeams` на настоящем git (тест «мои задачи…»: неотправленное видно до `pushTeams` и пропадает после).
Ограничение `stopTeamwork` в `stopServer` тестом не покрыто. Строка «не отправлено» с ошибкой сети в UI проверена живьём (bare-репо убран и
возвращён, «Повторить»).

- Шаблон репо команды (`templates/teamwork/`: названия колонок, заготовки документов, flow) и сообщения коммитов сервера — на русском;
  английский интерфейс показывает их как данные. Названия колонок шаблона UI переводит, остальное — нет.
- В поле «Названия колонок» настроек на английском видны русские названия из файла — это значения в репо команды, их правка меняет их для
  всех.
