# Этап 5 — доска, план по сессиям

Спека — [SPEC.md](SPEC.md), раздел 1 (принципы), 3.2 (колонки и движение), 3.4 (сверка) и раздел 6, «Этап 5». Макет —

После этапа Главная — доска дел: ни один блок не показывает ту же вещь, что и карточка.

Начинается после этапа 3 (дела, `web/src/api/desk.ts`) и источников этапа 4, которые уже в `desk`. Три сессии параллельно,
общие правила — как в [plan-0.md](plan-0.md); вёрстка — скилл `agentgraph-web`, токены «Пульта».

## Контракт

- Данные — только `web/src/api/desk.ts` (`useDesk`, `putDesk`, `moveDesk`, `closeDesk`) и `GET /api/desk` → `{ items, check }`.
- Чистая логика доски — `web/src/lib/desk-board.ts` (сессия board): раскладка по колонкам, «Начни с этого», срез по
  проектам, возраст в колонке. Без React, с тестами.
- Компонент доски — `web/src/screens/home/desk/DeskBoard.tsx` с пропсами `{ project?: string }`. Его монтирует
  `HomeScreen.tsx` (сессия home).
- Сверка «N из N» — `GET /api/desk/check` → `{ sources: Array<{ slug; title; kind: 'source' | 'watcher'; result: CheckResult; usual?: number }>, at }`
  (сессия top на сервере; собирается из `CheckResult` источников и наблюдателей, своего не хранит).

## Правила

- **«Начни с этого» без модели:** просрочено → срок сегодня → дольше всех мой ход → самое свежее в «Новом».
- **Одна вещь — одно место на Главной.** Если карточка показывает MR, ни один другой блок его не показывает.
- **Ход и почему — с карточки**, а не из отдельных блоков: «автор ответил на 2 замечания», «CI упал».
- **Перенос руками** держится до следующего изменения вещи (правило уже в `src/desk/rules.ts`), на карточке видно, кто
  подвинул последним.

## Порядок слияния

board → top → home. После — ревью, полный прогон, проверка в браузере утреннего сценария аудита A 1.1 целиком и критерия
«нет блока, который показывает ту же вещь, что и карточка».
